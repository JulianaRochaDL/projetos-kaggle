# Titanic — Kaggle

## Sobre o projeto

Projeto desenvolvido a partir do **Titanic Tutorial**, disponibilizado pelo Kaggle.

O objetivo foi acompanhar e executar as etapas propostas no tutorial, utilizando o dataset de passageiros do Titanic para praticar análise de dados e conceitos introdutórios de Machine Learning.

## Análise dos dados

Durante o tutorial, foram exploradas informações dos passageiros, como:

- Sexo dos passageiros
- Classe do passageiro (`Pclass`)
- Idade (`Age`)
- Número de irmãos/cônjuges (`SibSp`)
- Número de pais/filhos (`Parch`)
- Tarifa (`Fare`)
- Sobrevivência (`Survived`)

Também foram analisadas as taxas de sobrevivência de acordo com o sexo e a classe dos passageiros.

## Machine Learning

O tutorial apresenta um modelo de **Random Forest**, utilizando as características:

- `Pclass`
- `Sex`
- `SibSp`
- `Parch`

A variável utilizada como resposta é `Survived`.

Nesta etapa, o objetivo foi acompanhar e executar o código apresentado no tutorial para compreender o processo de treinamento do modelo e geração das previsões.

## Tecnologias utilizadas

- Python

- Jupyter Notebook
- Kaggle
